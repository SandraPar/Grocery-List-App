# Grocery List App 🛒

A simple Python console application to manage your grocery list.  
This app allows users to **add**, **remove**, and **view** items in their grocery list in a user-friendly menu interface.

## Features

- Add items to your grocery list
- Remove items from your grocery list
- View your current grocery list
- Simple and intuitive command-line interface
- Handles invalid input gracefully


bash
Copy code
python shopping_app.py
Follow the menu prompts to add, remove, or view items.
